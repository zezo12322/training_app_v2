## Instructions

1. Run the app on your device/emulator
2. Navigate to each screen
3. Take screenshots (use device screenshot or emulator tools)
4. Rename and place them in this folder
5. Update README.md image links if needed

## Recommended Tools
- **Android**: Built-in screenshot (Power + Volume Down)
- **iOS**: Built-in screenshot (Power + Volume Up)
- **Emulator**: Use emulator screenshot button
- **Desktop**: Use Snipping Tool or similar

## Image Specifications
- **Format**: PNG (preferred) or JPG
- **Resolution**: 1080x1920 or higher for mobile
- **Size**: < 1MB per image (optimize if needed)
- **Orientation**: Portrait for mobile screens, landscape for tablets/web
