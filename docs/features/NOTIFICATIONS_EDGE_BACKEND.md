# OneSignal External Notification Backend (No Firebase Functions)

Because the Firebase project is on the Spark (free) plan and enabling required APIs for Cloud Functions (with latest gen) needs Blaze, we replaced the callable function approach with a simple HTTPS endpoint you can host cheaply or for free (e.g. Cloudflare Workers, Vercel Edge Function, Fastify micro VM, Fly.io, Render, etc.).

## Contract (POST JSON)
Endpoint: `NOTIF_ENDPOINT` (passed to the app via `--dart-define=NOTIF_ENDPOINT=https://your-worker.example.com/send`)
Body JSON:
```json
{
  "userIds": ["uid1", "uid2"],
  "title": "Title text",
  "content": "Body text",
  "data": { "type": "badge", "badgeId": "points_100" }
}
```
Response (success): HTTP 200-299 any JSON.
Failure: non-2xx -> logged by app.

## Security Expectations
- The endpoint must hold the OneSignal REST API Key privately (never ship it to the Flutter app).
- Validate inputs (array length limits, string lengths) to avoid abuse.
- (Optional) Require a short-lived signed token (JWT/HMAC) generated by your auth backend to ensure only your app can call it.

## Sample Cloudflare Worker (JavaScript)
```js
export default {
  async fetch(req, env) {
    if (req.method !== 'POST') return new Response('Only POST', { status: 405 });
    const body = await req.json().catch(() => null);
    if (!body || !Array.isArray(body.userIds) || body.userIds.length === 0) {
      return new Response('Invalid body', { status: 400 });
    }
    const { userIds, title, content, data } = body;
    const appId = env.ONESIGNAL_APP_ID; // set in worker env vars
    const apiKey = env.ONESIGNAL_REST_KEY;
    if (!appId || !apiKey) return new Response('Missing OneSignal config', { status: 500 });

    const payload = {
      app_id: appId,
      include_external_user_ids: userIds,
      channel_for_external_user_ids: 'push',
      headings: { en: title || '' },
      contents: { en: content || '' },
      data: data || {},
    };
    const resp = await fetch('https://api.onesignal.com/notifications', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json; charset=utf-8',
        'Authorization': `Basic ${apiKey}`,
      },
      body: JSON.stringify(payload),
    });
    const json = await resp.json().catch(() => ({}));
    if (!resp.ok) {
      return new Response(JSON.stringify(json), { status: resp.status });
    }
    return new Response(JSON.stringify({ id: json.id, recipients: json.recipients }), { status: 200 });
  },
};
```
Deploy in Cloudflare:
- `wrangler secret put ONESIGNAL_APP_ID`
- `wrangler secret put ONESIGNAL_REST_KEY`

## Flutter Run Example
```powershell
flutter run --dart-define=ONE_SIGNAL_APP_ID=YOUR_APP_ID --dart-define=NOTIF_ENDPOINT=https://your-worker.example.com/send
```

## Sending From App
```dart
final service = ref.read(notificationServiceProvider);
await service.sendNotification(
  userIds: ['some-uid'],
  title: 'Badge Unlocked!',
  content: 'You earned the 100 points badge',
  data: { 'type': 'badge', 'badgeId': 'points_100' },
);
```
